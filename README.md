# Furnifold

Furnifold is a browser-based space planner. Measure a room, place furniture at its real dimensions, and compare arrangements before buying or moving anything.

## Project status

Repository setup. The first milestone is a measured 2D room editor with one sample bedroom and manual room setup. See the [product brief](docs/Furnifold_Product_Brief.md) for scope and acceptance criteria.

## Working from GitHub

This repository is the source of truth for Furnifold's code, assets, and project documentation. Start each task from the current GitHub branch and commit completed changes here. Use GitHub's editor or a cloud development environment when working without a local checkout.

- `docs/` holds product and implementation documentation.
- `src/` will hold app source and assets imported by the app.
- `public/` will hold assets that must be served directly.
