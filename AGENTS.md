# Furnifold project instructions

- Use `akshayattri/furnifold` on GitHub as the source of truth. Read the current files and branch before making changes.
- Commit Furnifold source, reusable assets, and project documentation back to this repository. Prefer direct GitHub edits or cloud execution so the user's computer does not need a project checkout or dependency installation.
- Read [the product brief](docs/Furnifold_Product_Brief.md) before implementing product changes. It defines the first milestone and acceptance criteria.
- Keep credentials and user-created room data out of version control.
